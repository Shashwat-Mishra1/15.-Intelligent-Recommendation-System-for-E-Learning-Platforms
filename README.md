
# Intelligent Recommendation System for E-Learning Platforms

## Project Overview
An AI-based e-learning application that recommends courses and learning resources based on students' interests, skills, learning history, and performance.

## Technologies Used
- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite
- HTML, CSS, JavaScript

## Main Features
- Student registration and login
- Course browsing and filtering
- Course enrollment
- Quizzes and saved quiz scores
- Course completion tracking
- Personalized course recommendations
- Learning analytics dashboard
- Admin student performance reports
- CSV report export

## Installation

1. Install Python.
2. Clone this repository.
3. Open a terminal in the project folder.
4. Create and activate a virtual environment.
5. Install dependencies using requirements.txt.
6. Configure the application's required environment variables.
7. Run the application using its documented startup command.
